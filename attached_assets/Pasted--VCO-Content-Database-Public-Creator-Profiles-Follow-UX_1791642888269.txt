# VCO Content Database – Public Creator Profiles & Follow UX

Please extend the existing Creator experience with attractive public Creator profiles.

First inspect what already exists and reuse current Creator, gallery, authentication, follow and profile functionality wherever possible.

## Public Creator Profile

Each active Creator should have a public profile page with:

- Profile photo
- Optional cover image
- Display name and unique profile URL
- Short biography
- Optional public contact email
- Optional website and Instagram links
- Follower count
- Follow / Unfollow button
- Visual grid of published Creator galleries and events

Use the existing VCO design language, but make the page feel premium, editorial and photography-focused.

Do not build another admin-style page.

Only published and publicly accessible galleries should appear.

## Creator Hover Card

When hovering over a Creator name on desktop, show a compact profile preview with:

- Avatar and name
- Short bio
- Follower count
- Follow button
- View Profile action

On mobile, provide a tap-friendly alternative.

Creator names throughout the public platform should link consistently to the Creator profile.

Keep hover interactions accessible and avoid intrusive popups.

## Creator Studio Profile Editing

Allow Creators to edit their public profile in the existing Creator Studio:

- Profile image
- Cover image
- Display name
- Biography
- Public contact details
- Social links

Keep the editing experience visual, simple and intuitive.

Do not require completion of optional profile fields.

## Follow Functionality

Registered users can follow and unfollow Creators.

Requirements:

- One follow relationship per user/Creator
- Accurate follower counts
- A simple Following section in the user account
- No duplicate follows
- No self-following
- No notifications or social feed in this phase

## Privacy & Security

- Never expose the private account email automatically.
- Public contact information must be explicitly provided.
- Protect profile edits with Creator ownership checks.
- Validate external links and uploaded images.
- Respect existing moderation and suspension rules.
- Avoid public exposure of unpublished content.

## Implementation

Inspect existing code first.

Reuse existing profile and social infrastructure.

Make the smallest necessary changes.

Preserve Stripe, Credits, premium media and all future monetization functionality.

No production deployment without approval.

Keep testing focused.

Provide a concise implementation report.
