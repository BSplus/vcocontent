# VCO Content Database – Storage Cost Audit & External Object Storage Evaluation

We expect the VCO Content Database to grow significantly in terms of photos, videos, galleries and Creator uploads.

Our priority is to keep long-term storage costs predictable and low without compromising reliability, media quality or existing functionality.

Before making any changes, audit the current storage architecture.

## 1. Current Storage Architecture

Identify:

- Where uploaded photos are stored
- Where videos are stored
- Where thumbnails and previews are stored
- Where AI-generated temporary files are stored
- Whether Replit Object Storage is currently used
- Whether media files are stored in PostgreSQL
- Current storage usage by file category
- Existing storage costs, where available
- Current data transfer and download architecture
- Existing cleanup and retention mechanisms

Distinguish application database storage from media file storage.

Do not assume that changing PostgreSQL will reduce media storage costs.

## 2. Evaluate External Object Storage

Compare the existing solution with:

- Cloudflare R2
- Backblaze B2

Evaluate:

- Storage costs
- Download and bandwidth costs
- API request costs
- S3 compatibility
- Integration complexity
- Private media access
- Signed download URLs
- Creator uploads
- Nextcloud imports
- Video processing
- Backup and recovery
- Data residency options

Use realistic scenarios of:

- 100 GB
- 500 GB
- 1 TB
- 5 TB

Include realistic assumptions for monthly downloads and API operations.

Identify whether serving media directly from object storage can reduce Replit bandwidth and VM workload.

## 3. Recommended Architecture

Propose the simplest architecture that:

- Keeps the existing Replit application
- Preserves PostgreSQL and all existing metadata
- Uses external object storage for large media files where beneficial
- Supports both official VCO and Creator content
- Preserves existing access permissions
- Supports future premium downloads and Credits
- Avoids unnecessary duplicate files
- Maintains existing AI processing workflows

Keep the existing Nextcloud archive integration.

## 4. Migration Safety

Do not migrate anything yet.

Evaluate how existing media references could be migrated without breaking:

- Gallery URLs
- Image previews
- Download permissions
- AI metadata
- Creator ownership
- Download statistics
- Premium content restrictions

Propose a safe, incremental migration strategy with verification and rollback.

## 5. Final Report

Provide a concise report with:

1. Current storage architecture
2. Current media storage usage
3. Current costs or cost limitations
4. Estimated costs at 100 GB, 500 GB, 1 TB and 5 TB
5. Recommended provider
6. Required code changes
7. Migration risks
8. Expected cost savings

Do not modify storage providers, migrate files, change production settings or deploy anything without explicit approval.

Priority: Minimise recurring costs while preserving the existing VCO Content Database and its functionality.
